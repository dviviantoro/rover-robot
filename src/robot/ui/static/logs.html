Logs

The orchestrator streams its own records here as they happen — no SSH, no guessing which file to tail. The other services run as separate processes, so their output is read from their log file, or from the journal when systemd is running the stack.

orchestrator log level

Debug makes the orchestrator log the model's raw reply before any stripping — the fastest way to see why a language tag or an action marker went wrong.
